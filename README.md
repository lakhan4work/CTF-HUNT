🛡️ CTF Platform

A Web-Based Capture The Flag (CTF) Platform for Peer Learners

📌 Overview

CTF Platform is a full-stack web application designed to host and manage Capture The Flag (CTF) cybersecurity challenges. It enables peer learners to solve categorized challenges, submit flags, track scores in real-time, and compete via a dynamic scoreboard.

The platform includes authentication, admin controls, challenge management, and a structured backend for secure flag validation.

This project demonstrates full-stack development, secure backend handling, and cybersecurity-oriented system design.
